## 项目结构梳理（竹里集 bamboo-basket-site）

- 单文件 Worker 应用：`worker/index.js`（419 行，约 3.3MB）。前三行是 base64 内嵌的 3 张 JPG（`BAMBOO_VALLEY_BASE64` / `BASKET` / `TEA`），运行时按 `/assets/bamboo-*.jpg` 直接解码返回，不依赖静态文件托管。
- 后端：内存态数据（`products`、`orders` 数组），无 D1/R2（`.openai/hosting.json` 里 static/d1/r2 均为 null）。路由在 `api()`：
  - 商品：GET `/api/products`、POST/PUT/DELETE（需 `x-admin-token`）
  - 订单：POST `/api/orders`（演示）、GET `/api/orders`（需 admin）、PUT `/api/orders/:id` 改状态

  - 支付：`/api/lianlian/create-payment` + `/api/lianlian/notify`（RSA-SHA1 签名，V3 商户收单接口）
- 前端：`APP_HTML` 字符串里内嵌整站 CSS + 原生 JS（无框架），单页切换 `location.pathname` 判断 `/admin`；支持 zh/en/de/it 四语言，文案在 `UI_TEXT` / `UI_EXTRA`。
